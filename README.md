### 2. **AWS-SOC-Lab**
Why: Cloud security can't be learned from a book. You need to get your hands dirty.

What it does: A realistic AWS environment with logging, monitoring, and incident scenarios. When something goes wrong (and it will), I investigate it using Splunk.

Built with: AWS (IAM, VPC, CloudTrail, GuardDuty), Splunk, incident response playbooks.

### 3. **Security-Automation**
Why: Manually doing repetitive security work is a waste of your best people.

What it does: Python scripts that parse logs, correlate events, integrate with APIs, and automate security workflows. Think of it as glue for your security stack.

Built with: Python, API integrations, log processing, data correlation.

### 4. **Threat-Hunting**
Why: Waiting for alerts to find threats is like waiting for smoke to see the fire.

What it does: Threat hunting queries, investigation frameworks, and playbooks that help you proactively search for adversaries hiding in your environment.

Built with: Splunk searches, behavioral analysis, MITRE ATT&CK framework.
